# 天使カエル・レース Prototype v0.5

1対1の高速レース操作を確認するためのブラウザ試作です。

## 起動
`index.html` をブラウザで開いてください。PC / タッチ操作の両方を想定しています。

## 操作
- 左スティック / 矢印・WASD: 旋回
- ジャンプ / Space: 1回=ジャンプ、2回=羽ばたき加速、3回=滑空して最高速へ
- 滑空中: 約5秒ごとの羽ばたきタイミングで再度ジャンプすると滑空延長
- 舌 / E: コーナー内側の木を最優先して掴む。長押しで旋回し、離して解除
- A / J: ミカエル=パンチ、ガブリエル=水弾（小反動）
- B / K: ミカエル=泡弾、ガブリエル=水レーザー（大反動）
- 操作交代 / C: ミカエルとガブリエルを切り替えて挙動確認

## 今回の仕様
- 高速ほど通常旋回が弱くなり、最高速では大きなカーブをライン取りで攻略する必要があります。
- コース外のガード草へぶつかると速度低下します。
- 舌アンカー旋回は保持時間が短すぎると曲がり不足、長すぎると引っ張られて減速します。
- コーナリング用アンカー舌はライバルとの接触・重なりの影響を受けません。
- アンカーが近くにない場合のみ、舌はライバルを狙い、相手を少し減速・自分を一瞬加速させます。
- ミカエルのパンチ／泡弾は相手を弾きます。直接減速ではなく、壁へ押し込む用途です。
- ガブリエルの水技は横方向へ放水し、その反対方向への反動で機体を動かします。
- ガブリエルBの水レーザーは壁まで届く長い描画＋大反動で、舌なしの急旋回にも使えます。
- CPUガブリエルもカーブで水反動を使います。

## 調整候補
最高速、通常旋回限界、滑空維持受付（現状およそ3.8〜5.9秒）、舌の最適解除時間、水レーザー反動量は次版でプレイ感を見ながら詰める前提です。

## v2.3 バーニングクライム／禁断スキル
- ミカエルさん固有スキル「バーニングクライム」を追加。初期から装備候補。
- 約1.15秒だけ通常高度より上空へ跳ぶ。毒霧、飛び道具、舌などを回避できる。
- バーニングクライム中はガード草を越えられるため、ヘアピンのショートカットを狙える。
- 上空中はチェックポイントを取得しないため、コースを飛び越えて周回を不正に進めることはできない。
- バーニングクライム終了時にコース外なら「コースアウト」。低速で最寄りのコースまで自動で歩いて復帰し、飛行状態を失う。
- バーニングウィング中は舌で掴めない。舌を出した側が熱でひるむ。
- バーニングウィング中への叩き落とし、キック、タックル等の接触攻撃は攻撃側が弾かれる。
- クリア後の禁断スキル「時間停止」を追加。1レースにつき1回、3秒間だけ相手と相手由来の弾・効果を停止する。
- 時間停止はエンディング後に解禁され、通常の自由2スキル枠へ装備可能。

- 習得シューティングは世界全体を縮小する表示を廃止し、本編と同じ描画のまま近距離カメラで追従する方式へ変更。キャラと泡弾が大きく見える。

- 新コースの周回判定を、全チェックポイントへの接触依存からコース進行セグメント方式へ変更。コーナーを少しカットしても周回が止まりにくく、各コースで3周表示・判定が進む。
- レース開始位置も各コースのスタート地点・進行方向から自動配置するよう修正。

## v2.13 コース交差・コーナー木・CPU復帰・イベント生物
- コース同士が近づきすぎて十字路のように見える箇所を再設計。非隣接区間の間隔を広げ、ガード草の外幅も少し整理。
- 難しいカーブの木アンカー配置を自動計算し直し、進行方向の曲がる側＝コーナー内側の頂点へ置く方式に変更。緩いカーブには無理に置かず、強いコーナーほど少し奥へ配置。
- CPUの進路計算を古いチェックポイント番号依存から、現在いるコース区間＋先読み方式へ変更。
- CPUが壁に当たった場合は反射を繰り返さず、コース中心へ戻して次の区間方向へ向ける復帰処理に変更。
- プレイヤーの壁衝突も強い反射を廃止。速度を落として壁沿いの進行方向へ流すため、一度のミスで何度も後方へ跳ね返されにくい。
- 習得シューティングの敵はカエル描画を使用しない。リヴァイアさん＝ピラニア、アスモデウスさん＝ザリガニ、アザゼルさん＝トンボ、ベリアルさん＝クモの簡易専用描画を追加。
- 池はリヴァイアさん→アスモデウスさん、森はアザゼルさん→ベリアルさんの順に交代。各個体は一つの名前だけを表示する。

## v2.14 ショートカット前提の周回判定
- 「指定チェックポイントを全部踏まないと周回にならない」方式を廃止。
- コース形状上できるショートカットは、原則として正規の走法として認める。ショートカットさせたくない場所は、チェックポイントではなくコース設計・壁配置側で防ぐ。
- 周回判定はスタート／ゴールラインの方向付き通過だけで行う。
- 正方向にゴールラインを横切ると LAP +1。逆方向に横切ると LAP -1（最低 LAP 1）。
- そのため、ゴール付近を往復しても前進分と逆走分が相殺され、周回数だけを不正に増やせない。
- レース開始位置はゴールライン直後に置き、スタート直後の通過が1周として数えられないようにした。

## v2.15 ゴールライン高速通過修正
- 舌ターンなど高速移動時、1フレームでゴール判定線を飛び越えて周回が数えられない問題を修正。
- 現在位置だけを見るのではなく、前フレーム位置→現在位置の移動線分がゴールラインを横切ったか判定する方式へ変更。
- ゴールラインの有効幅を広げ、コーナー内側の木を舌で回る実戦ラインでも周回判定に入るよう調整。
- 正方向通過で+1、逆方向通過で-1というショートカット前提のルールは維持。

## v2.16 ゴール内側ライン／壁スライド／習得イベント1体化
- ゴールラインの横方向有効幅を大幅に広げ、スタート直後の鋭角コーナーを木に舌で巻き付いて内側から抜けるラインでも周回として認識するよう調整。
- ショートカット合法・正方向+1／逆方向-1のルールは維持。
- 習得シューティングは途中で敵が交代しない。森のバーニングウィング習得はアザゼルさんのみ、池のバーニングクライム習得はリヴァイアさんのみ。
- アスモデウスさん、ベリアルさんの専用描画は残し、後の時間系スキルイベント等で使えるよう保留。
- 壁接触時にコース中心へ座標を飛ばしていた処理を廃止。壁へめり込んだ分だけ最小限押し戻す方式へ変更。
- 壁接触後は約0.3秒のスライド猶予を設け、鋭角コーナーで同じ壁判定を連打してバウンドし続ける状態を抑制。
- CPUも同じ考え方で壁沿いに進行方向へ復帰し、連続反射を避ける。

## v2.17 鋭角コーナー壁ハマり修正
- 鋭角コーナーで壁判定が隣接区間間を行き来し、何度も押し返されて抜けられなくなる問題を修正。
- 壁接触時の安全位置をコース中心線から約125pxまで内側へ寄せ、境界ぎりぎりへ戻さないよう変更。
- 壁接触後約0.4秒はコース中心方向へ弱く引き戻す「脱出補助」を追加。
- 壁接触後の向きは、その場の接線だけではなく2区間先のコース方向へ向けるため、V字の袋へ戻りにくい。
- 瞬間移動感を抑えるため、中心線へ完全スナップはせず、壁を貫通した分から安全な位置までの補正に限定。

## v2.18 壁衝突時の着地

- CPUも同様に着地するが、復帰不能になりにくいよう最低速度を少し高めに設定。
- 鋭角コーナーの脱出補助中も低速・地上状態を維持し、壁間をバウンドし続けないようにした。
