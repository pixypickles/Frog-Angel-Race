# 天使カエル・レース Prototype v0.5

1対1の高速レース操作を確認するためのブラウザ試作です。

## 起動
`index.html` をブラウザで開いてください。PC / タッチ操作の両方を想定しています。

## 操作
- 左スティック / 矢印・WASD: 旋回
- ジャンプ / Space: 1回=ジャンプ、2回=羽ばたき加速、3回=滑空して最高速へ
- 滑空中: 約5秒ごとの羽ばたきタイミングで再度ジャンプすると滑空延長
- 舌 / E: コーナー内側の木を最優先して掴む。長押しで旋回し、離して解除
- A / J: ミカエル=パンチ、ガブリエル=水弾（小反動）
- B / K: ミカエル=泡弾、ガブリエル=水レーザー（大反動）
- 操作交代 / C: ミカエルとガブリエルを切り替えて挙動確認

## 今回の仕様
- 高速ほど通常旋回が弱くなり、最高速では大きなカーブをライン取りで攻略する必要があります。
- コース外のガード草へぶつかると速度低下します。
- 舌アンカー旋回は保持時間が短すぎると曲がり不足、長すぎると引っ張られて減速します。
- コーナリング用アンカー舌はライバルとの接触・重なりの影響を受けません。
- アンカーが近くにない場合のみ、舌はライバルを狙い、相手を少し減速・自分を一瞬加速させます。
- ミカエルのパンチ／泡弾は相手を弾きます。直接減速ではなく、壁へ押し込む用途です。
- ガブリエルの水技は横方向へ放水し、その反対方向への反動で機体を動かします。
- ガブリエルBの水レーザーは壁まで届く長い描画＋大反動で、舌なしの急旋回にも使えます。
- CPUガブリエルもカーブで水反動を使います。

## 調整候補
最高速、通常旋回限界、滑空維持受付（現状およそ3.8〜5.9秒）、舌の最適解除時間、水レーザー反動量は次版でプレイ感を見ながら詰める前提です。

## v1.6 キャラクター／初戦
- 初戦の対戦相手を「無個性カエル」に変更。ミカエルとは違う黄緑寄りの緑。固有能力なし、Aパンチ／B泡弾。
- ミカエルだけ翼を淡い金色・クリーム色の特別仕様に変更。
- ラファエル：黄色。風属性。通常より約22%曲がりやすい。
  - A エアバリア：約2秒、舌を弾き、壁衝突時の速度低下を無効。
  - B エアブースト：1レース3回限定の強加速。
- ウリエル：オレンジ。土属性。パンチ等の押し出しがやや強い。
  - 後ろから舌で掴まれてもウリエル自身は減速しない。
  - A タックル：入力方向に応じて真横へ強く移動し、接触した相手を大きく弾く。
  - B ロックフォール：岩を放物線風に投射し、命中相手を大きく横へ弾く。
- レース勝利数に応じて初戦カエル→ラファエル→ウリエルの順で対戦相手が変化する試作進行。

## v1.7 大会構成・ルシファー・リリス
- 各コースを「大会」として扱う構造へ変更。通常大会は2回戦制。
  - 1回戦：無個性カエル固定。
  - 2回戦：ガブリエル／ラファエル／ウリエル／ルシファー／リリスからランダム。
- コースを増やすほど大会を増やせる構造。
- 3つの通常競技場を制覇するとマスタークラス解禁フラグが立つ。マスタークラスの対戦相手はベルゼブブ。
- ルシファー：グレー。炎系の系統だが炎そのものは表示しない。
  - A 叩き落とし：近距離相手を強制着地させ、ジャンプ→羽ばたき→滑空をやり直させる。
  - B チャージブースト：B長押し中に最大1.8秒チャージ、離すとチャージ量に応じて加速。旋回操作と同時使用しづらいスマホ向けリスク設計。
- リリス：ピンク。舌射程390（通常270）。
  - A キック：近くの後方相手を蹴り、相手を減速・自分を加速。
  - B 「惑いの瘴気」：怪しい紫の弾。命中すると約2.2秒、プレイヤーの上下左右入力を反転。
- ベルゼブブ：黒＋蛍光緑を想定。現段階ではマスタークラス配置とキャラ枠まで。

## v1.8 ベルゼブブさん／カワズさん

  - B ポイズンブースト：後方へ毒を噴いて加速し、約4秒残る毒霧を設置。霧に触れた相手も強制落下。
  - ベルゼブブさんが舌で掴まれている間にA/Bを押すと、掴んでいる相手へ毒反撃して強制落下。

## v2.2 スキル枠
- ミカエルさんのA/Bカテゴリ分けを廃止。
- ホームでは「スキル1（Aボタン）」「スキル2（Bボタン）」として、習得済みの全スキルから自由に2つ選択。
- パンチ／泡弾／バーニングウィング／他キャラから習得した技は、どちらの枠にも装備可能。
- 同じ技を2枠へ重複装備しないよう、同一技を選ぶともう一方の枠と入れ替える。

## v2.3 ハイジャンプ／禁断スキル
- ミカエルさん固有スキル「ハイジャンプ」を追加。初期から装備候補。
- 約1.15秒だけ通常高度より上空へ跳ぶ。毒霧、飛び道具、舌などを回避できる。
- ハイジャンプ中はガード草を越えられるため、ヘアピンのショートカットを狙える。
- 上空中はチェックポイントを取得しないため、コースを飛び越えて周回を不正に進めることはできない。
- ハイジャンプ終了時にコース外なら「コースアウト」。低速で最寄りのコースまで自動で歩いて復帰し、飛行状態を失う。
- バーニングウィング中は舌で掴めない。舌を出した側が熱でひるむ。
- バーニングウィング中への叩き落とし、キック、タックル等の接触攻撃は攻撃側が弾かれる。
- クリア後の禁断スキル「時間停止」を追加。1レースにつき1回、3秒間だけ相手と相手由来の弾・効果を停止する。
- 時間停止はエンディング後に解禁され、通常の自由2スキル枠へ装備可能。

## v2.4 クリア後・池の時間系スキル
- タイムラグ／時間停止はどちらもクリア後要素へ変更。
- エンディングを見るだけでは時間停止は解禁されない。
- クリア後に池イベントへ行くと「タイムラグ」を習得可能。
- タイムラグ：6秒間、自分は通常速度のまま、相手と相手由来の弾・効果の時間を50%にする。
- タイムラグ習得後、操作キャラをカワズさんにして池イベントへ行くと禁断領域が出現し、「時間停止」を習得。
- 時間停止：1レース1回、3秒間、相手と相手由来の弾・効果を完全停止。

## v2.5 時間系スキル演出
- 時間停止中は、操作キャラ以外のコース・相手・相手由来の弾や効果を強い青系モノクロ表示にする。
- 操作中のミカエルさん／カワズさんと自分の弾は通常色のまま残し、「自分だけ時間から外れている」見た目にする。
- 画面全体に青い時間停止オーバーレイ、枠線、「TIME STOP」表示を追加。
- タイムラグ中も同系統の青み・低彩度演出を使うが、時間停止より弱くし、「TIME LAG」表示にする。

## v2.6 ラップ表示／ハイジャンプ調整
- HUDのLAP表示を実際の周回数に連動。2周目は2/3、3周目は3/3と更新される。
- ハイジャンプを一定高度の浮遊から、上昇→頂点→下降の山なり軌道に変更。
- ハイジャンプは約1.05秒、速度も上限を抑え、空中の旋回性能を大きく低下。細いヘアピン程度なら越せるが、広い区間を横断するには距離が足りない設計。
- ハイジャンプ中もチェックポイント判定は通常通り行う。ショートカット制限はチェックポイント無効化ではなく、ジャンプの物理的な飛距離で行う。
- 着地時にコース外なら従来通り低速歩行でコースへ復帰。
- レース画面右上の「操作交代」ボタンとCキーの操作交代を削除。
